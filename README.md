# ADHD ASMR

**[Читать на русском](#русский)**

ADHD ASMR is a fully vibe-coded client-side mod for Minecraft Java 26.3 on Fabric. It plays YouTube videos in a corner of your HUD. The included queue is built around ASMR, with soap cutting and rug washing, and the same player can play regular YouTube videos that allow embedding.

## Installation

Install Minecraft Java **26.3**, **Java 25 or newer**, and **Fabric Loader 0.19.5 or newer**. Place ADHD ASMR and the following mods in the instance's `mods` folder:

- [Fabric API](https://modrinth.com/mod/fabric-api/versions?g=26.3) **0.161.0+26.3 or newer**, for Minecraft 26.3.
- [MCEF Modern](https://modrinth.com/mod/mcef-modern/version/dwiy9wKy) **0.3.3 for 26.3** or a compatible newer release. MCEF Modern may download Chromium on first use.
- [Mod Menu](https://modrinth.com/mod/modmenu/versions?g=26.3) **21.0.1** is required. It adds a shortcut to the settings screen. **F4** opens the same screen in-game.

## Features

- YouTube player with standard playback controls, adjustable size, and four HUD positions.
- The player stays visible in the pause menu, inventory, and chat. Leaving the world hides and pauses playback.
- Queue with video titles and thumbnails. Add a link with Enter or the add button, play an item, copy links, remove items, shuffle, or clear the queue.
- An included queue and a button to refresh it from [`videos.json`](https://github.com/alexoff35/adhd-asmr-mod/blob/main/videos.json).

## Default controls

| Key | Action |
| --- | --- |
| F4 | Open settings and queue |
| F6 | Previous video |
| F7 | Pause or resume |
| F8 | Next video |
| F9 | Show or hide the player |
| F10 | Enable or disable the player cursor |
| Numpad + / − | Increase / decrease YouTube volume by 5 |

All controls can be remapped in Minecraft. If YouTube blocks autoplay, press **F10** and click **Play**.

## Русский

**ADHD ASMR** — полностью вайбкодед клиентский мод для Minecraft Java 26.3 на Fabric. Он воспроизводит YouTube-видео в углу HUD. Стартовая очередь собрана под ASMR: нарезку мыла и мойку ковров. Через тот же плеер можно смотреть обычные ролики YouTube, если для них разрешено встраивание.

### Установка

Понадобятся Minecraft Java **26.3**, **Java 25 или новее** и **Fabric Loader от 0.19.5**. Положите ADHD ASMR и следующие моды в папку `mods` нужного экземпляра игры:

- [Fabric API](https://modrinth.com/mod/fabric-api/versions?g=26.3) **от 0.161.0+26.3**, для Minecraft 26.3.
- [MCEF Modern](https://modrinth.com/mod/mcef-modern/version/dwiy9wKy) **0.3.3 для 26.3** или более новая совместимая версия. При первом использовании MCEF Modern может скачать Chromium.
- [Mod Menu](https://modrinth.com/mod/modmenu/versions?g=26.3) **21.0.1** обязателен. Он добавляет кнопку настроек в список модов. В игре этот же экран открывается клавишей **F4**.

### Возможности

- Плеер YouTube со стандартным управлением, настройкой размера и выбором одного из четырёх углов HUD.
- Видео остаётся на экране в меню паузы, инвентаре и чате. При выходе из мира плеер скрывается и ставит видео на паузу.
- Очередь с названиями и миниатюрами. Можно добавить ссылку через Enter или кнопку, запустить ролик, скопировать ссылку, удалить запись, перемешать или очистить очередь.
- Встроенная подборка и кнопка обновления очереди из [`videos.json`](https://github.com/alexoff35/adhd-asmr-mod/blob/main/videos.json).

### Клавиши по умолчанию

| Клавиша | Действие |
| --- | --- |
| F4 | Открыть настройки и очередь |
| F6 | Предыдущее видео |
| F7 | Пауза / воспроизведение |
| F8 | Следующее видео |
| F9 | Показать / скрыть плеер |
| F10 | Включить / выключить курсор плеера |
| Num + / − | Повысить / понизить громкость YouTube на 5 |

Все клавиши можно переназначить в Minecraft. Если YouTube заблокировал автозапуск, нажмите **F10** и кликните **«Воспроизвести»**.
